The Doxygen manual is not part of this build

The full Doxygen manual — call graphs, caller graphs, #include dependency graphs and the annotated source browser — is mounted here by build_mkdocs.py from build/docs/html. Either it has not been generated in this tree yet, or you are reading the offline export in prebuilt/, which leaves it out because of its size (about 100 MB). Everything else — guides, module theory, measurements and the API reference — is in this manual. 

python3 build_docs.py --open   # the Doxygen manual on its own
python3 build_mkdocs.py         # this site, with the manual mounted here
