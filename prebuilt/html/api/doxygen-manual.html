    The Doxygen manual¶

    The complete Doxygen manual is published as part of this site, at /doxygen/. It is not a duplicate of the API reference: it carries three classes of artefact that come out of Graphviz and out of Doxygen's source parser, and that no Markdown rendering of the XML can reproduce.

    •   Call and caller graphs

      For every function, both directions. The interesting ones — MFTLRemeshEnsembleParallel, MFTLRedistributeWithOwners — are emitted as interactive SVG, so they pan and zoom rather than merely existing.

      Function index

    •   Annotated sources

      The full source browser, cross-linked in both directions, with comments preserved. The prose in this library lives next to the code, so the annotated sources are a first-class part of the manual rather than a dump.

      Source files

    •   Include dependency graphs

      Which header includes which, drawn. This is the fastest way to check the layering rule — a header may only include headers from a strictly lower layer — because a violation shows up as an edge pointing the wrong way.

      Topics by layer

    •   A second search index

      Doxygen's own client-side search, which indexes members and their signatures rather than page text. Useful when you half-remember a parameter name.

      Open the manual

    Rebuilding it

    The manual is copied into this site from build/docs/html, which is what python3 build_docs.py produces. python3 build_mkdocs.py runs both steps in the right order. If the links above 404, the Doxygen pass has not run in this tree yet:

    python3 build_docs.py          # -> build/docs/html
python3 build_mkdocs.py        # -> build/site, with /doxygen/ inside it

    The zero-warning criterion

    WARN_IF_UNDOCUMENTED, WARN_IF_INCOMPLETE_DOC, WARN_NO_PARAMDOC and WARN_IF_UNDOC_ENUM_VAL are all on, and the manual currently builds with zero warnings. That is the acceptance criterion, so a new function without @param/@return fails python3 build_docs.py --strict. Run it after touching any header.
