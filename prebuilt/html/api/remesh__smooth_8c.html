    function MFTLDetectFeatures¶

    Flags feature edges and classifies every vertex as free, ridge or corner. 

    int MFTLDetectFeatures (
    MFTL_Object * obj,
    double angle_degrees,
    double corner_angle_degrees,
    MFTL_RemeshStats * stats
)

    Recomputes tris.normal first (after a split, new triangles have none). Then, in linear passes over undirected edges (no fan walks, which would miss the closing edge of an open fan):

    • edges: MFTL_FLAG_FEATURE on both halves of every edge whose face normals differ by more than angle_degrees, and on every mesh-boundary edge; cleared elsewhere, so a smoothed-out fold stops being a feature. A missing twin counts as a boundary only on an owned triangle on a ghost it is the rim of the halo, and MFTL_FLAG_BOUNDARY decides;
    • vertices: MFTL_FLAG_FEATURE (ridge point) for exactly two feature edges continuing within corner_angle_degrees of straight; MFTL_FLAG_CORNER for one, three or more, or two that turn more sharply; neither for none.

    Parameters:

    • obj The mesh. Flags rewritten, tris.normal refreshed.
    • angle_degrees Normal-angle threshold in degrees; \(\ge 180\) disables it, leaving only boundaries as features.
    • corner_angle_degrees Turn angle above which a two-edge vertex is a corner.
    • stats May be MFTL_NULL. Receives the edge and vertex-class counts.

    Returns:

    The number of undirected feature edges.

    ** **

    Performs no MPI. Each rank operates on its own partition.

    function MFTLSmoothTangential¶

    Tangential smoothing: iterations Jacobi sweeps in which each vertex moves towards its neighbourhood centre, PROJECTED onto the subspace its feature class allows. 

    void MFTLSmoothTangential (
    MFTL_Object * obj,
    const MFTL_RemeshParameters * params,
    int iterations
)

    • Corner: locked (0D).
    • Ridge: the pull towards the midpoint of its two feature neighbours, projected onto the ridge tangent (1D). Moving to the midpoint itself cuts the chord and erodes the ridge.
    • Free: the pull towards the target point of smooth_mode, minus its component along the area-weighted vertex normal (2D). Without the projection, Laplacian smoothing shrinks the surface.

    Vertex normals come from MFTLComputeVertexNormals(), refreshed every sweep; a vertex whose normal is zero (degenerate one-ring) stays put. Steps are scaled by smooth_relaxation and capped at smooth_max_step_fraction of the shortest incident edge. All differences are minimum-image vectors and positions are wrapped, so the smoother is seam-safe. Frozen vertices and ghosts are not moved but are read, which makes a distributed sweep exact without communication. Jacobi updates make the result independent of pool order.

    Parameters:

    • obj The mesh; positions updated in place.
    • params Supplies smooth_mode, smooth_relaxation and smooth_max_step_fraction.
    • iterations Sweeps to perform.

    Note:

    Requires MFTL_DERIVED_TOPOLOGY and a current feature classification.

    ** **

    Performs no MPI. Each rank operates on its own partition.

    function fan_halfedges¶

    Outgoing half-edges of v in rotational order, plus fan openness. 

    static int fan_halfedges (
    const MFTL_Object * obj,
    int v,
    int * out,
    bool * open
)

    MFTLGetVertexOneRingHalfedges does the walk but does not report whether the fan closed, and every caller here needs to know: on an OPEN fan there is one more incident EDGE than there are outgoing half-edges, and it is reachable only as the incoming half-edge prev(first). A consumer that iterates edges and does not account for it silently drops one, and then misclassifies every boundary vertex.

    Parameters:

    • obj The mesh.
    • v Vertex index.
    • out [ MFTL_REMESH_RING_MAX ] outgoing half-edges, rotational order.
    • open Set when the fan is open, i.e. v is on a boundary.

    Returns:

    Number of half-edges written, or 0 if the walk was truncated.

    function free_displacement¶

    Displacement of a FREE vertex, projected onto its tangent plane. 

    static bool free_displacement (
    const MFTL_Object * obj,
    int v,
    const int * fan,
    int n_fan,
    bool open,
    MFTL_SmoothMode mode,
    double disp,
    double * min_edge_sq
)

    The neighbourhood sums are accumulated as minimum-image OFFSETS from the vertex, so a fan straddling a periodic seam is averaged correctly.

    Parameters:

    • obj The mesh.
    • v A vertex with no feature edges.
    • fan Outgoing half-edges of v, from fan_halfedges().
    • n_fan Their count.
    • open true when the fan is open.
    • mode Which neighbourhood the target point is built from.
    • disp The displacement, projected onto the tangent plane.
    • min_edge_sq Shortest incident squared edge length, for the step clamp.

    Returns:

    true if a displacement was produced.

    function open_fan_last_neighbour¶

    The neighbour an outgoing-half-edge walk cannot reach: the closing edge of an open fan. 

    static inline int open_fan_last_neighbour (
    const MFTL_Object * obj,
    int first
)

    first is the fan's first outgoing half-edge v->w. Its triangle is (v, w, x), so next(first) targets x, and the edge v-x exists only as the incoming half-edge prev(first). Without it a boundary vertex is short one neighbour and lands in the wrong feature class.

    Parameters:

    • obj The mesh.
    • first First outgoing half-edge of the fan.

    Returns:

    The missing neighbour's vertex index.
