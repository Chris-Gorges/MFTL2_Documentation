    Naming conventions the reference assumes¶

    You will read the index faster knowing three rules the library follows without exception:

    • MFTLPascalCase is a function, MFTL_PascalCase is a type, MFTL_UPPER_CASE is a macro or constant. snake_case is a file-static helper, and it appears here only because EXTRACT_STATIC is on — the real algorithms live in those.
    • A function returns int, either MFTL_SUCCESS or MFTL_ERROR. The same MFTL_ERROR (−1) doubles as the "no such entity" index sentinel.
    • Every function's documentation says whether it is collective (every rank of the ensemble's communicator must call it, including ranks holding no body) or rank-local. Most MFTLEnsemble* functions are collective and most functions taking a single MFTL_Object * are rank-local, but not all: read the paragraph.
