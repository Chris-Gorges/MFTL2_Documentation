    File List¶

    Here is a list of all files with brief descriptions:

    • dir doxygen
    • file groups.dox Definition of the Doxygen module hierarchy.
    • dir include
      • file mftl_arrayfunctions.h Flat-array utilities: LSD radix sort and duplicate removal.
      • file mftl_bvh.h Linear BVH over triangle primitives, exact triangle-triangle predicates, and (distributed) object-object contact detection.
      • file mftl_communication.h Distributed memory: redistribution, ghost synchronisation, the spatial halo, and the exchange engine they share.
      • file mftl_constants.h Scalar constants, math macros and the assertion policy.
      • file mftl_core.h Convenience umbrella header.
      • file mftl_ensemble.h The library handle: the MPI/physical domain plus the bodies this rank holds, the per-body collectives, and the collective geometry passes.
      • file mftl_geometry.h Periodic-aware geometry: minimum image, ownership lookup, triangle and vertex geometry, closest points, and signed distance on a lattice.
      • file mftl_io.h Mesh output in VTK formats: a serial legacy debug dump and a parallel VTK XML ( .vtu ) writer.
      • file mftl_memory.h Allocation policy, cache-line-aligned pool blocks, and array growth.
      • file mftl_meshgen.h Mesh construction: indexed triangle lists, icospheres, and marching cubes on a (distributed, periodic) lattice.
      • file mftl_object.h The mesh container: pool lifecycle, derived connectivity, Morton ordering, and the hot-loop iterators.
      • file mftl_remeshing.h Isotropic surface remeshing split, collapse, flip, tangential smoothing serial and distributed.
      • file mftl_topology.h Half-edge topology: entity flags, implicit index arithmetic, navigation, and connectivity maintenance.
      • file mftl_topology_change.h Topology changes breakup and coalescence by distributed signed-distance rasterisation and marching cubes, on the partition as it stands.
      • file mftl_types.h Core data structures of MFTL the single place every struct is defined.
      • file mftl_vectoroperations.h Small fixed-size vector helpers.
    • dir src
      • dir arrayfunctions
        • file radixsort.c LSD radix sort over 8-bit digits, for keys and for key/value pairs.
      • dir bvh
        • file bvh_build.c Primitive access, and building, refitting and destroying the hierarchy: Morton keys, stable radix sort, top-down radix split, bottom-up fit.
        • file bvh_internal.h Private helpers shared by the BVH module's translation units.
        • file bvh_predicates.c The narrow phase: exact orientation, triangle-triangle intersection, and exact triangle-triangle distance.
        • file bvh_traverse.c Dual-tree traversal over an explicit stack, the batched leaf-leaf narrow phase, and the ensemble contact pipeline.
      • dir communication
        • file comm_internal.h Private helpers shared by the communication module's translation units.
        • file comm_stats.c The rank-local accumulator behind MFTL_RedistributeStats .
        • file exchange.c The MPI datatypes, the generic variable-length exchange, and the neighbourhood allgather.
        • file ghost_sync.c Ghost synchronisation of one per-vertex 3-vector (position or normal) with the topology unchanged.
        • file redistribute.c Redistribution: re-partitioning a distributed mesh over the process grid.
        • file spatial_halo.c The spatial halo: the parts of body B near this rank's share of body A, delivered as shadow objects. Design rationale: mftl_communication.h §6.
      • dir ensemble
        • file ensemble.c Ensemble lifecycle: the MPI/physical domain plus its list of objects.
        • file ensemble_reduce.c Per-body reductions and exclusive scans over the ranks that HOLD each body, with a certified neighbourhood route and an exact global fallback.
        • file ensemble_update.c The fused per-timestep geometry + quality pass, and the collective vertex-normal pass.
      • dir geometry
        • file signed_distance.c Bounded rasterisation of a triangle mesh's signed distance onto a lattice window, signed by angle-weighted pseudo-normals.
        • file triangle_geometry.c Per-triangle geometry for a whole mesh, and the closest point on a triangle.
        • file vertex_geometry.c Area- and angle-weighted vertex normals.
      • dir io
        • file vtk_legacy.c The single-rank legacy .vtk debug dump of an object's raw pool: no filtering, no periodic unwrapping, no communication.
        • file vtu_writer.c The parallel VTK XML writer: selection, periodic unwrapping, block assembly, and the two output backends (POSIX per rank, MPI-IO shared).
      • dir mesh_creation
        • file marching_cubes.c Marching cubes with a 256-case table GENERATED from one face rule, and an extractor that names every vertex by the lattice edge it lies on.
        • file mesh_builder.c Indexed triangle list -> half-edge mesh: the one conversion point, so the half-edge conventions are established in exactly one place.
        • file sphere_creation.c The icosphere: an icosahedron, N rounds of 1-to-4 midpoint subdivision, one final projection onto the sphere.
      • dir object
        • file derived.c The derived connectivity arrays, and the Morton renumbering of the pools.
        • file object.c Object lifecycle and the single allocation authority for both pools.
      • dir remeshing
        • file remesh_comm.c The remeshing module's own MPI. See remesh_comm.h for why it is its own file and what each entry point costs.
        • file remesh_comm.h Every MPI call the remeshing module makes, and nothing else.
        • file remesh_compact.c Removing dead entities, and re-densifying global ids.
        • file remesh_dispersed.c Distributed remeshing for bodies SMALLER than a rank box: move the bodies, not the cut planes.
        • file remesh_driver.c The remeshing pass: sweep order, convergence, and what is refreshed when.
        • file remesh_internal.h Helpers shared by the remeshing translation units. Not a public header.
        • file remesh_ops.c The three topological operators and their approval predicates.
        • file remesh_parallel.c Distributed remeshing: the shift/freeze phase schedule.
        • file remesh_smooth.c Feature classification and tangential smoothing.
      • dir topology
        • file topology.c Whole-mesh connectivity operations: twin rebuilding, boundary marking, integrity checking and connected-component labelling. Navigation is inline in mftl_topology.h .
      • dir topology_change
        • file topo_cluster.c The reconstruction lattice, the clusters, and each rank's window.
        • file topo_comm.c EVERY MPI call of the topology-change module.
        • file topo_detect.c Detection: which pairs of triangles are a thin feature, and of which kind.
        • file topo_driver.c The two public entry points, in collective order.
        • file topo_internal.h Internal interfaces of the topology-change module.
        • file topo_reconstruct.c The field and the surface: rasterisation, the overlap exchange, the bias, and marching cubes on this rank's cells.
        • file topo_split_bodies.c From triangle soup to bodies: distributed component labelling, the id decision, and the objects themselves.
