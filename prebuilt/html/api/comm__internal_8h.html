    Detailed Description¶

    Author:

    Christian Gorges

    Date:

    2026-08-14

    Not a public header: nothing outside src/communication/ may include it, and nothing here is exported. It holds the two data structures that both the redistribution and the ghost synchronisation need.

    variable MFTLCommStats¶

    The accumulator. Rank-local, zeroed by MFTLRedistributeStatsReset() . 

    MFTL_RedistributeStats MFTLCommStats;

    The accumulator. Zero-initialised at load, so a caller that never resets still reads a valid (whole-run) total.

    function cs_alloc¶

    Records an allocation of bytes into the redistribution counters. 

    static inline void cs_alloc (
    size_t bytes
)

    The byte count is what was REQUESTED, summed over the run not a peak and not what the allocator actually mapped. It is a churn measure: the question it answers is how much a persistent workspace would stop re-requesting.

    function gt_hash¶

    Scatters a global id over a sparse table's index space (multiplicative avalanche hash). 

    static inline unsigned gt_hash (
    int gid
)

    The identity index clusters badly: a partition's ids are many dense runs that alias under the mask, and linear probing then degrades to quadratic insertion (measured 127 ms against 0.76 ms on a 327 680-triangle body).

    Parameters:

    • gid The global id.

    Returns:

    A well-mixed 32-bit value.

    function gt_probe¶

    Finds the slot gid occupies, or the free slot it would occupy. 

    static inline int gt_probe (
    const mftl_gid_table * t,
    int gid,
    bool * found
)

    Sparse mode stops at the first slot not of the current epoch (sound because nothing is ever deleted). The mode branch is constant per use and predicts perfectly.

    Parameters:

    • t The table.
    • gid The global id.
    • found Set to true if the returned slot holds gid.

    Returns:

    The slot index.
