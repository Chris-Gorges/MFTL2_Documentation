    Detailed Description¶

    Author:

    Christian Gorges

    Date:

    2026-08-14

    Both public entry points run redistribute_core(); MFTLRedistribute() is MFTLRedistributeWithOwners() with the geometric owner rule.

    Most of a partition does not move, so kept entities never touch the wire format:

    kept -> a PERMUTATION of the pool: records and positions are gathered into scratch in final order and written back. arrivals -> de-duplicated through a global-id table (gt_* in comm_internal.h) and appended. twins -> REPAIRED, not rebuilt: a twin between two kept triangles is an index remap; only half-edges that lost their partner are re-paired.

    Why the incremental twin repair is complete. Kept-ness is decided per triangle, so a kept half-edge's twin survives iff the twin's triangle is kept, and then both are remapped consistently. A half-edge whose twin did not survive can only pair with another such half-edge, so the repair set is closed under the twin relation and bucketing it against itself finds every pair a full MFTLRebuildTwins() would. tests/test_redistribution.c re-runs MFTLRebuildTwins() after a redistribution and asserts that nothing changes.

    function MFTLRedistribute¶

    Re-partitions every local object with the geometric owner rule, in one communication round for the whole ensemble. 

    int MFTLRedistribute (
    MFTL_Ensemble * ens
)

    • Analysis. Every entity's owner is recomputed (MFTLGetOwnerProc()); each OWNED triangle is destined for its owner plus the owners of its corners and edge neighbours. Entities this rank keeps are marked, not packed. Ghost triangles are never forwarded (their owner sends the authoritative copy). Bodies nobody saw change are left alone (MFTLRedistributeSetSkipUnchangedBodies()).
    • Route. One MPI_Allreduce (LOR) decides whether any destination lies outside the 26-neighbourhood; if so the exchange uses comm_cart.
    • Exchange. Vertices, triangles and one 7-int header per (body, destination) as three payloads of one MFTLExchangeStart(); all bodies share the messages, so the message count is independent of the body count.
    • Rebuild. Kept entities are compacted in place into the layout [kept owned | new owned | kept ghost | new ghost]; arrivals are de-duplicated by global id; only half-edges that lost their twin are re-paired; out_he_idx and the derived arrays are emitted inline. Bodies that arrived are created, bodies left empty destroyed.

    Parameters:

    • ens The ensemble; every local object is repartitioned in place. Its triangle centres must be current, ghosts included (MFTLEnsembleComputeTriangleGeometry(); a body whose MFTL_DERIVED_GEOMETRY bit is clear is recomputed first, see the file comment; asserted in Debug).

    Returns:

    MFTL_SUCCESS, or MFTL_ERROR on a NULL ensemble.

    ** **

    Must be called by every rank of the ensemble's communicator. Ranks holding no bodies must call it too; an ensemble without bodies is a no-op.

    Warning:

    Invalidates every pool index, every MFTL_Object pointer and all cached geometry except vertex positions (see the file comment).

    function MFTLRedistributeSetShrinkSlack¶

    Lets redistribution return outgrown pool capacity (default 0 = off). 

    void MFTLRedistributeSetShrinkSlack (
    double slack
)

    After each rebuild every touched body is offered to MFTLObjectShrinkToFit(obj, slack). Useful after generation, where rank 0 built every body whole ( \(3440\cdot4^r+128\) bytes per icosphere) and keeps a sliver of each in a full-size block. A pure memory policy: counts, contents, derived bits and partition stamps are unchanged, and ranks may differ. It does not lower the generation PEAK. Measured: about 8 % less capacity for about 2 % of the redistribution time, hence off by default.

    Parameters:

    • slack Shrink when capacity > slack * n; use MFTL_SHRINK_SLACK_DEFAULT. Zero or negative disables.

    ** **

    Performs no MPI. Each rank operates on its own partition.

    function MFTLRedistributeSetSkipUnchangedBodies¶

    Allows redistribution to skip bodies nobody saw change (default ON). 

    void MFTLRedistributeSetSkipUnchangedBodies (
    bool on
)

    A rank's state after a redistribution is a function of (global topology, owner map) only positions decide the owner map but, once it is fixed, moving a vertex within its cell changes nothing about who holds what. A body is skipped when no rank saw any of its entities change owner and nothing stamped it partition-dirty (MFTLObjectMarkPartitionDirty()): all classification, packing and rebuild work for it is omitted. The verdict is agreed per body with one MFTLEnsembleReduceBodies() call.

    The skip is EXACT, slot for slot: because a rebuild is not idempotent (an owned vertex whose incident triangles are all remote is dropped and re-received at the end of the run), a body is rebuilt once more after it stops changing before it may be skipped (partition_settled). parallel_advection_redistribute_list --digest and test_skipping_reproduces_the_full_rebuild compare set and slot-order digests. Anything that rewrites global ids or flags, or creates/destroys entities outside MFTLObjectSetCounts(), must stamp the object dirty.

    Parameters:

    • on true to allow the skip, false to rebuild every body every call.

    ** **

    Must be called by every rank of the ensemble's communicator. Every rank must pass the SAME value: it changes the number of collectives (checked by a Debug checksum).

    function MFTLRedistributeWithOwners¶

    MFTLRedistribute() with the ownership rule supplied per body. 

    int MFTLRedistributeWithOwners (
    MFTL_Ensemble * ens,
    const MFTL_OwnerMap * maps
)

    maps is indexed by LOCAL SLOT, maps[o] describing ens->local_objects[o]: the argument never crosses a rank, so the slot needs no global meaning (and a body-id-indexed array would cost O(bodies in the ensemble) per call).

    Parameters:

    • ens The ensemble.
    • maps [ens->n_local_objects] owner maps in local_objects order, or MFTL_NULL for the geometric rule for every body. When non-NULL, both arrays of every entry must be set (asserted): there is no per-body fallback to the geometric rule.

    Returns:

    MFTL_SUCCESS, or MFTL_ERROR on an invalid ensemble.

    ** **

    Must be called by every rank of the ensemble's communicator. The maps must agree on every shared entity (MFTL_OwnerMap).

    function check_object_lists_agree¶

    Debug-only: do all ranks agree on the size of the body-id space and on the skip switch? 

    static void check_object_lists_agree (
    const MFTL_Domain * dom,
    int n_bodies_global
)

    Equal id spaces are the observable consequence of "every rank added the same bodies in the same order"; disagreement would merge entities into the wrong body. The skip switch changes the number of collectives, so disagreement would deadlock. {sig, ~sig} under one MPI_MIN detects a difference in either direction. The local body count legitimately differs and is excluded.

    Parameters:

    • dom Supplies the communicator.
    • n_bodies_global Size of the body-id space.

    function collect_destinations¶

    Destination analysis: which ranks each OWNED triangle goes to, and what this rank keeps. 

    static int collect_destinations (
    const MFTL_Object * obj,
    int my_rank,
    const char *restrict is_neighbor,
    const int *restrict tri_owner,
    const int *restrict vert_owner,
    vertex_dedup * dd,
    char *restrict keep_t,
    char *restrict keep_v,
    mftl_int_buffer * tri_ids,
    mftl_int_buffer * vert_ids,
    int * touched,
    int * n_touched
)

    Destinations of triangle t: its owner, the owners of its three corners and the owners of its three edge neighbours (the halo rule). This rank is one destination like any other, recorded as keep flags instead of a copy. Ghost triangles are never forwarded. Interior triangles, whose seven candidates all name one rank, take a register-only fast path (an XOR-OR test); otherwise the candidates are collected in first-seen order, which fixes the wire order and hence the arrival slot order.

    Parameters:

    • obj The mesh.
    • my_rank This rank.
    • is_neighbor [nproc] flags marking the 26-neighbourhood.

    function rebuild_object¶

    Rebuilds one object from its kept entities and its arrivals (no sort, no full twin rebuild). 

    static void rebuild_object (
    MFTL_Object * obj,
    const body_state * bs,
    const MFTL_PackedVertex * recv_v,
    const MFTL_PackedTriangleComplex * recv_t,
    int my_rank,
    rebuild_scratch * s
)

    Steps: (0) a body with nothing kept and nothing arriving is emptied and its pools released; (1) gather kept records and positions; (2) de-duplicate the arrivals by global id (a vertex arrives once per sender sharing it, and the copies are identical; a triangle has one owner and cannot arrive twice); (3) map logical to final slots; (4) size the pools (geometric pre-growth, so jittering counts do not reallocate every step) and place the kept entities; (5-6) remap kept half-edges, retiring twins that did not survive into the repair list, and emit out_he_idx and the derived arrays inline; (7) write the arrivals; (8) repair twins.

    Parameters:

    • obj The mesh, rewritten in place. On return: valid topology and positions, MFTL_DERIVED_TOPOLOGY set, cached geometry unspecified, partition_dirty cleared.
    • bs Per-body state from build_kept_lists().
    • recv_v Received vertex records.
    • recv_t Received triangle records.
    • my_rank This rank.
    • s Reusable scratch, grown monotonically across calls.

    function refresh_geometry_before_routing¶

    Recomputes the triangle geometry of a body whose centres the library knows to be out of date, before routing by them. 

    static void refresh_geometry_before_routing (
    MFTL_Object * obj
)

    Called when MFTL_DERIVED_GEOMETRY is clear: no pass over every triangle since the last ghost sync, topology change or rebuild. That catches the inconsistent cases no pass at all, a pass over the owned triangles only (ghost centres stale), a pass before the ghost sync, a second redistribution without one (arrivals unspecified) in O(1) per body. It cannot catch owned vertices moved after a full pass: that leaves every holder with the same stale centres, so the partition lags one step but stays consistent.

    Local and deterministic: it computes what the caller should have, from the same positions, so it needs no agreement between ranks. Debug asserts if the centres were actually stale, so a test cannot pass by relying on it.

    Parameters:

    • obj The mesh; routed by the geometric rule.

    function split_kept_run¶
