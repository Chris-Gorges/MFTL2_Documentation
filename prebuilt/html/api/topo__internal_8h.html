    function MFTLTopoBuildObjects¶

    Builds this rank's objects for every kept component it owns anything of, with PROVISIONAL ids, and swaps them for the old bodies in the ensemble. 

    int MFTLTopoBuildObjects (
    MFTL_Ensemble * ens,
    const MFTL_TopoLattice * lat,
    MFTL_TopoCluster * cl,
    int n_cl,
    MFTL_TopoPiece * pieces,
    const MFTL_TopoComponent * comps,
    int n_comps,
    int ** created,
    long long *** vkeys,
    long long *** tkeys
)

    Parameters:

    • ens The ensemble; every listed body of a reconstructed cluster is erased from it.
    • lat The lattice, for the wall flags of rim edges.
    • cl The clusters.
    • n_cl Their number.
    • pieces [n_cl] this rank's marching cubes output, labelled.
    • comps The decided components, sorted by (cluster, label).
    • n_comps Their number.
    • created malloc'd body ids of the new objects, sorted.
    • vkeys [n_new] per new object, the lattice key of each vertex (malloc'd).
    • tkeys [n_new] per new object, the lattice key of each triangle.

    Returns:

    Number of new objects created on this rank; created lists their body ids.

    function MFTLTopoCommExchange¶

    Personalised exchange of records of stride doubles. 

    double * MFTLTopoCommExchange (
    const MFTL_Domain * dom,
    const double * records,
    const int * dest_counts,
    int stride,
    bool global_path,
    int * n_recv,
    int * src_counts
)

    Parameters:

    • dom The domain: communicator and neighbourhood graph.
    • records Grouped by destination rank, dest_counts[r] records for rank r.
    • dest_counts [nproc] records per destination.
    • stride Doubles per record.
    • global_path Whether any rank has a destination outside its neighbourhood; agreed inside, so a local value is enough.
    • n_recv Records received.
    • src_counts Optional [nproc]: records received from each rank.

    Returns:

    Received records, malloc'd, grouped by source rank in rank order.

    function MFTLTopoCommReply¶

    Sends reply (one record ofstride doubles per received request, in receive order) back to the requesters. The inverse ofMFTLTopoCommExchange() with the counts swapped. 

    double * MFTLTopoCommReply (
    const MFTL_Domain * dom,
    const double * reply,
    const int * src_counts,
    int stride,
    bool global_path
)

    Parameters:

    • dom The domain.
    • reply One record per received request, in receive order.
    • src_counts [nproc] requests received from each rank, as MFTLTopoCommExchange() reported them.
    • stride Doubles per record.
    • global_path Whether the request exchange went global; agreed inside.

    Returns:

    The replies, in the order the requests were packed.

    function MFTLTopoDecideComponents¶

    Decides every component's fate and id, identically on every rank. 

    int MFTLTopoDecideComponents (
    const double * all,
    int n_all,
    const MFTL_TopoCluster * cl,
    int n_cl,
    const int * bodies,
    const long long * body_size,
    int n_bodies,
    int min_tris,
    int * n_bodies_global,
    MFTL_TopoComponent ** comps,
    MFTL_TopologyStats * stats
)

    Parameters:

    • all Gathered component records.
    • n_all Their number.
    • cl The clusters; refused ones are skipped.
    • n_cl Their number.
    • bodies [n_bodies] the listed body ids, sorted and unique.
    • body_size [n_bodies] global triangle count of each listed body, in the order of bodies.
    • n_bodies Their number.
    • min_tris Closed components with fewer triangles are discarded.
    • n_bodies_global In: the id watermark. Out: raised by the new ids.
    • comps Sorted by (cluster, label); malloc'd.
    • stats Created/retired/discarded counts are written.

    Returns:

    The number of components.
