Detailed Description

Dual-tree traversal over an explicit stack, the batched leaf-leaf narrow phase, and the ensemble contact pipeline.

Author
Christian Gorges
Date
2026-08-16

An explicit stack of (nodeA, nodeB) pairs keeps the loop-invariant state in registers, cannot overflow the call stack (a dual traversal is not tail-recursive), and lets leaf-leaf candidates be collected into batches of 64 independent tests – the shape a future SIMD narrow phase needs, which would then change flush_batch() only. The batch is not vectorised yet.

Periodic images: two bodies on opposite faces of a periodic domain are neighbours although a domain length apart in stored coordinates, so the pair is traversed once per image offset in {-L, 0, +L} per periodic axis (at most 27), each gated by one root-box test.

Reports every contacting primitive pair between two hierarchies.

For every periodic image of B whose shifted root box overlaps A's root, a dual-tree descent over an explicit stack of node pairs splits the node with the larger box volume; leaf-leaf candidates are collected into batches of 64 and passed to MFTL_TriTriProximity() at tolerance MAX(tol_A, tol_B). Only pairs with a LOCAL A-side primitive are tested, so a distributed run reports each contact once.

Parameters

bvhAHierarchy over object A.
objBThe object bvhB was built from. May equal objA with a distinct second tree: the self-proximity query, where pairs sharing a vertex are dropped and each unordered pair is kept once (smaller triangle global id first).
bvhBHierarchy over object B.
callbackInvoked per contacting pair; must not modify either object.
user_dataPassed through to callback.
Rank-local:
Performs no MPI. Each rank operates on its own partition.

◆ MFTLEnsembleIntersectObjects()

int MFTLEnsembleIntersectObjects ( MFTL_Ensemble * ens,
const MFTL_BVHBuildParams * params,
IntersectionCallback callback,
void * user_data )

Contact detection for a whole ensemble: build, measure, exchange, attach, traverse, destroy.

  1. MFTL_GenerateLBVH() for every body this rank holds;
  2. MFTLSpatialHaloResolveRadii() and MFTL_BVHSetGlobalRadius() – the envelope is a fraction of the body, whose size is only known collectively;
  3. MFTLExtendSpatialHaloNearBodies() with those envelopes, which returns the patches AND the candidate body pairs (no all-pairs list is enumerated);
  4. MFTL_BVHSetHalo() per patched body; a body held nowhere here but patched gets a tree over a shared empty object;
  5. MFTL_IntersectObjects() per candidate pair (A = smaller body id). A self pair uses a second, tight (zero-envelope), patch-free A-side tree.

Cost: trees O(bodies held), traversals O(candidate pairs); two collective steps independent of the body count.

Parameters
ensThe ensemble.
paramsBuild parameters, or MFTL_NULL for the defaults.
callbackInvoked per contacting pair.
user_dataPassed through.
Returns
MFTL_SUCCESS, or MFTL_ERROR on invalid arguments.
Collective:
Must be called by every rank of the ensemble's communicator. Guarded by n_bodies_global (at least 2, or 1 with self_pairs). A contact between bodies whose holders are more than one cell apart is not found: the halo only ships along comm_graph.
