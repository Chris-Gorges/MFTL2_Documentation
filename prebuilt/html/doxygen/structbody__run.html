Detailed Description

One contiguous run of one body's entities inside the arrival stream.

Every rank packs body by body, and the (neighbour) alltoallv concatenates the received blocks in source order, so the arrivals are a sequence of per-body runs whose lengths are shipped in the header payload. A running offset over the headers recovers the runs without sorting the arrivals.
