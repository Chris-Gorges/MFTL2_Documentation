◆ domain_init_comm()

int domain_init_comm ( MFTL_Domain * domain)
static

Builds the MPI topology of a domain, once, so no hot path calls an MPI topology function again.

  • comm_cart: the Cartesian communicator (no reordering), which defines the grid-coordinate-to-rank mapping;
  • rank_map: that mapping as a flat array (owner lookup is per entity);
  • comm_graph: a symmetric distributed graph over the distinct ranks of the 26 surrounding cells, for neighbourhood collectives whose message count is bounded by the degree rather than the process count. On thin periodic grids several offsets alias one rank (listed once, with its first offset in neighbor_offset), and the graph may contain this rank itself.

On failure the communicators created so far are reset to MPI_COMM_NULL so MFTLEnsembleDestroy() can clean up.

Parameters
domainThe domain; comm_world must be set.
Returns
MFTL_SUCCESS, or MFTL_ERROR if a communicator could not be created.

◆ MFTLEnsembleCreate()

MFTL_Ensemble * MFTLEnsembleCreate ( MPI_Comm comm,
int cuts[3],
double global_min[3],
double global_max[3],
bool is_periodic[3],
int initial_object_capacity )

Creates an ensemble: the global domain and its MPI topology.

Duplicates comm (the library communicates only on its own duplicate), validates cuts[0]*cuts[1]*cuts[2] == size(comm) and the bounds, then builds the Cartesian communicator (no rank reordering), the rank_map lookup table, the grid factors and the distributed graph over the up to 26 distinct neighbouring cells (periodic wrap-around included).

Parameters
commBase communicator, usually MPI_COMM_WORLD.
cutsProcess grid {nx, ny, nz}; product = communicator size.
global_minLower corner of the domain box.
global_maxUpper corner; global_max >= global_min per axis.
is_periodicPer-axis periodicity, or MFTL_NULL for none.
initial_object_capacityInitial length of the object list (grows on demand).
Returns
The new ensemble, or MFTL_NULL on invalid input or MPI failure.
Collective:
Must be called by every rank of the ensemble's communicator.

Adds an object, links it to the domain, and gives it its body id.

The ensemble takes ownership (MFTLEnsembleDestroy() destroys the object).

◆ MFTLEnsembleUpdateGlobalCounts()

void MFTLEnsembleUpdateGlobalCounts ( MFTL_Ensemble * ensemble)

Refreshes every local object's global_n_triangles / global_n_vertices and the ensemble's total_global_triangles.

Two SUM slots per body through MFTLEnsembleReduceBodies() (the local halves are just n_local, thanks to the ownership prefix), plus one scalar MPI_Allreduce for the ensemble total. A body's counts land only on the ranks holding it.

Parameters
ensembleThe ensemble.
Collective:
Must be called by every rank of the ensemble's communicator. Ranks holding no bodies must call it too.

double MFTLDomainGetHMin ( const MFTL_Domain * domain)

The narrowest rank box over the CUT axes: \(\min_{k:\,\mathrm{cuts}_k\ge2} L_k / \mathrm{cuts}_k\).

The length the distributed remesher's band condition and its dispersed/spanning classification are measured against. Axes with a single cut have no interior plane and are skipped.

Parameters
domainThe MPI/physical world.
Returns
The narrowest cut rank-box width; 0 when no axis is cut (one process).
Rank-local:
Performs no MPI. Each rank operates on its own partition. Identical on every rank.
