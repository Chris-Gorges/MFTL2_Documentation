Detailed Description

The parallel VTK XML writer: selection, periodic unwrapping, block assembly, and the two output backends (POSIX per rank, MPI-IO shared).

Author
Christian Gorges
Date
2026-08-14

Three separable phases: ANALYSE (which cells and points, which triangles straddle a seam; per rank, no MPI), ASSEMBLE (one contiguous byte block per DataArray; per rank) and EMIT (the only phase that differs between encodings and layouts). The time of an ASCII writer is spent in printf; the binary path's assembly is a memcpy.

◆ MFTLWriteVtu()

int MFTLWriteVtu ( MFTL_Ensemble * ensemble,
const char * filename_prefix,
const MFTL_VtkOptions * options )

Writes every local object of an ensemble as one VTK XML unstructured grid (all bodies in one point/cell list per piece).

Points are the vertices referenced by the written triangles (owned triangles may reference ghost vertices), plus three private points per triangle that straddles a periodic face; a seam vertex is therefore written by every rank with a triangle on it. Cells carry TriangleOwner, BodyID and optionally TriangleGID; points VertexOwner and optionally VertexGID. Uses compact connectivity when current, the half-edge records otherwise; no geometry precondition.

  • MFTL_IO_FILE_PER_RANK writes <prefix>_%05d.vtu per rank and <prefix>.pvtu on rank 0.
  • MFTL_IO_SINGLE_FILE writes one <prefix>.vtu with one Piece: one non-blocking MPI_Exscan + MPI_Allreduce pair places every block, rank 0 writes header, length prefixes and footer, and every rank writes its slice of each block with MPI_File_write_at_all (enabling two-phase collective buffering). The file is truncated to its exact size. Requires MFTL_VTK_BINARY and at most \(2^{31}-1\) points and \((2^{31}-1)/3\) cells (Int32 connectivity and offsets).
