Detailed Description

Area- and angle-weighted vertex normals.

Author
Christian Gorges
Date
2026-08-14

A SCATTER over triangles: each triangle gathers its three current positions through tris.verts and adds its weighted face normal into its three vertices; one streaming pass then normalises. The alternative GATHER (walk each vertex's fan) serialises dependent loads (he -> twin -> next) and measured 3.4x slower; a vertex-to-triangle CSR gather measured a dead heat with the scatter while costing 16 B/triangle and a rebuild per topology change (docs/analysis.md §1.5). verts.normal stays xyz-interleaved: the read-modify-write of three contiguous doubles is four memory operations per vertex against six for split arrays (1.20-1.25x in examples/layout_benchmark.c).

◆ scatter_angle_weighted_normals()

void scatter_angle_weighted_normals ( MFTL_Object * obj)
static

Scatters each face's UNIT normal times its interior angle at each corner.

All three corners share \(s = \norm{\vect{e}_1\times\vect{e}_2}\), so with \(d_{ij} = \vect{e}_i\cdot\vect{e}_j\): 

alpha_0 = atan2(s, d12),  alpha_1 = atan2(s, d11 - d12),  alpha_2 = atan2(s, d22 - d12)

( \(\vect{e}_1\cdot(\vect{e}_1-\vect{e}_2)\) is the dot product of the two edges at corner 1, and similarly at corner 2). atan2 is well conditioned for every angle, unlike acos near 0 and \(\pi\). Zero-area faces have no unit normal and are skipped.

Parameters
objThe mesh. verts.normal is accumulated into; the caller zeroes it.

◆ normalise_vertex_normals()

void normalise_vertex_normals ( MFTL_Object * obj)
static

Scales every accumulated vector to unit length, in place.

A vertex with no incident triangle stays exactly zero – a detectable "not computed" sentinel. The guard is a test against ZERO, not a small constant: area-weighted sums scale as a length squared, so any absolute threshold would zero the normals of a valid mesh with small enough triangles.

Parameters
objThe mesh. Each verts.normal entry is normalised in place.

◆ MFTLComputeVertexNormals()

void MFTLComputeVertexNormals ( MFTL_Object * obj,
MFTL_NormalWeighting weighting )

Unit vertex normals for every vertex of the pool, into verts.normal.

One flat pass over ALL triangles (ghosts included) scatters each weighted face normal into its three corners, then one pass normalises; a vertex without incident triangles gets the zero vector. Requires current tris.verts.

On a distributed mesh an OWNED vertex is exact without communication, because the redistribution halo is vertex-complete (every triangle incident to an owned vertex is present locally). A GHOST vertex misses its far-side faces and holds a normalised PARTIAL sum – plausible-looking and wrong. MFTLEnsembleUpdateVertexNormals() adds the exchange that makes ghosts exact.

Parameters
objThe mesh; verts.normal is overwritten for every vertex.
weightingMFTL_NORMAL_WEIGHT_AREA or MFTL_NORMAL_WEIGHT_ANGLE.
Rank-local:
Performs no MPI. Each rank operates on its own partition.
