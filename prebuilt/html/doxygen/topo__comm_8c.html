Detailed Description

EVERY MPI call of the topology-change module.

Author
Christian Gorges
Date
2026-09-25

Seven shapes, and how each scales:

topo_comm_allreduce_* a handful of values PER CLUSTER or per listed body. Clusters exist only where events were detected, so this is bounded by what happened, not by the ensemble. MFTLTopoCommAllgather the event list, and one record per (component, holder). Both are paid only on a step with events, and both are proportional to what changed. It is a comm_world collective ON PURPOSE: every rank must agree on the event list, including a rank two boxes away that will reconstruct part of a body it does not yet hold. MFTLTopoCommExchange / 26-neighbour personalised exchanges: the lattice MFTLTopoCommReply overlap, the component labels, the ghost ids. The global communicator only when some destination is provably outside the neighbourhood, which the caller detects and this file agrees on.

static

The shared body of the exchange and the reply: an alltoallv of doubles, on the graph or the global communicator.

On the graph path the per-rank counts are gathered into neighbour order and the result is scattered back into rank order, so callers see ranks either way. A rank reached through two stencil offsets (a thin periodic grid) is ONE entry of neighbors per offset; only the first occurrence carries data, the rest carry zero, so nothing is delivered twice. The graph's self-loop, if it has one, carries zero as well: callers merge their own contributions locally.
