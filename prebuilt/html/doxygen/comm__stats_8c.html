Detailed Description

The rank-local accumulator behind MFTL_RedistributeStats.

Author
Christian Gorges
Date
2026-08-25

A file-scope singleton written through the CS_* macros of comm_internal.h (the library is process-per-rank, so one accumulator per process suffices). It takes no collective, so leaving it on never synchronises what it measures.
