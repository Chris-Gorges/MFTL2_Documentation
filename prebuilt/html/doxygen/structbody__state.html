Detailed Description

What the analysis phase hands to the rebuild phase, per object.

The kept lists are OLD pool indices in final relative order: the owned run first, then the ghost run. Both runs are ascending, which keeps the gather in the rebuild a forward scan over the pool rather than a random walk.
