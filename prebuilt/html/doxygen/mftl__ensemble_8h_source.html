1/**
2 * @file mftl_ensemble.h
3 * @author Christian Gorges
4 * @date 2026-08-14
5 * @ingroup mftl_ensemble
6 *
7 * @brief The library handle: the MPI/physical domain plus the bodies this rank
8 * holds, the per-body collectives, and the collective geometry passes.
9 *
10 * An #MFTL_Ensemble owns one #MFTL_Domain and a gid-sorted list of the
11 * #MFTL_Object s this rank holds entities of. Geometry is split by SCOPE:
12 * `MFTLCompute*` (mftl_geometry.h) is one object, local, no MPI;
13 * `MFTLEnsembleUpdate*` (here) loops over the objects and adds exactly the
14 * collective the result needs -- a REDUCTION for the triangle quality
15 * statistics, an EXCHANGE for vertex normals. The one exception, for speed:
16 * MFTLEnsembleUpdate()'s kernel is file-static in src/ensemble/ensemble_update.c
17 * because its nine reduction accumulators must stay in registers (an
18 * address-taken struct across a translation unit measured 15 % slower,
19 * docs/analysis.md §1.6). Theory: src/ensemble/README.md.
20 */

45 * @collective

139/**
140 * @brief Which set of ranks a per-body reduction is taken over.
141 *
142 * @warning Must be the SAME on every rank: it selects between a neighbourhood
143 * and a `comm_world` collective, and disagreement deadlocks.
144 *
145 * There is no value that forces the neighbourhood route: whether it is exact is
146 * only known after the exchange, so it is always certified.
147 *
148 * @see MFTLEnsembleReduceBodies()
149 */

152 /**
153 * Neighbourhood route when certified exact, global route otherwise. The

159 * Always the `comm_world` reduction: exact for any ensemble, but

188/**
189 * @brief Reduces per-body values over the ranks that HOLD each body.
190 *
191 * The shape of every per-body collective in the library (quality statistics,
192 * global counts, the redistribution skip vote, body radii, remesher
193 * measurements): each rank contributes a row per body it holds, and every
194 * holder receives the combination over all holders. This is the only place the
195 * communicator for it is chosen.
196 *
197 * **Indexing by local slot.** @p values is `[n_local_objects][n_per_body]`,
198 * row `o` for `local_objects[o]`, reduced in place. A body-id-indexed buffer
199 * (the shape `MPI_Allreduce` needs) would cost every rank
200 * `O(bodies in the ensemble)` to learn about the few it holds.
201 *
202 * **Routes.** *Holders:* one `MPI_Neighbor_allgather` of counts and one
203 * `MPI_Neighbor_allgatherv` of `(body id, row)` records on `comm_graph`, then a
204 * local fold -- `O(local bodies x degree)`, independent of the process and body
205 * counts, exact iff every two holders of every body are graph neighbours.
206 * *Global:* `MPI_Allreduce` over a body-id-indexed staging buffer, one call per
207 * distinct operator. AUTO exchanges the records, certifies them, agrees the
208 * verdict with one `MPI_LAND` of an int, and on refusal discards them and takes
209 * the global route.
210 *
211 * **Certificate.** Let \f$H(X)\f$ be the holders of body \f$X\f$; each holder
212 * \f$R\f$ checks
213 *
214 * 1. \f$R\f$ owns at least one entity of \f$X\f$;
215 * 2. every rank owning a ghost of \f$X\f$ in \f$R\f$'s pool is a graph neighbour;
216 * 3. after the exchange, \f$R\f$ and every neighbour that published a record
217 * for \f$X\f$ span at most one cell per axis.
218 *
219 * *1 and 2 make \f$H(X)\f$ connected on the graph*: redistribution sends each
220 * triangle to the owner of each corner and edge neighbour, so the owners of two
221 * incident entities hold each other's entity as a ghost and, by 2, are graph
222 * neighbours; the surface is connected, and by 1 every holder is an owner.
223 * *3 makes a connected \f$H(X)\f$ a clique*: two holders \f$a, c\f$ at graph
224 * distance 2 would share a holder neighbour \f$m\f$, both would be in \f$m\f$'s
225 * record set, so by 3 their offsets from \f$m\f$ differ by at most one per axis
226 * and \f$c\f$ is in \f$a\f$'s 26-stencil -- a contradiction. Checking 3 on the
227 * halo-visible holders alone (before the exchange) is NOT sufficient: a body
228 * bent around a grid corner passes on every rank while its two ends never meet
229 * (`test_a_bent_body_is_certified_after_the_exchange`). An empty holder fails 1
230 * and vetoes (the state of a generated ensemble before its first
231 * redistribution). One conservative case: a periodic axis with 3 cuts, where a
232 * body occupying all three cells is refused.
233 *
234 * @warning Assumes each body is ONE CONNECTED surface. Nothing in MFTL produces
235 * another kind (topology changes give every component its own id); a
236 * caller assembling a disconnected body must pass
237 * #MFTL_BODY_REDUCE_SCOPE_GLOBAL.
238 *
239 * **Bitwise identity.** Contributions are folded in ascending SOURCE RANK
240 * order, this rank spliced in at its position, so every holder of a body
241 * obtains bit-identical results (a solver branching on them never splits the
242 * ranks). A self-loop in `comm_graph` (grids with a single cut on a periodic
243 * axis) is dropped, or a SUM would count this rank twice.
244 *
245 * @param ens The ensemble.
246 * @param[in,out] values `[n_local_objects * n_per_body]`, row-major by local
247 * slot: this rank's contribution in, the reduction out. May be
248 * #MFTL_NULL only when this rank holds no bodies.
249 * @param n_per_body Values per body, identical on every rank. 0 returns
250 * immediately on every rank, entering no collective.
251 * @param ops `[n_per_body]` operators, identical on every rank. Mixing them is
252 * free on the holder route.
253 * @param scope Route selection; identical on every rank.
254 * @return #MFTL_SUCCESS, or #MFTL_ERROR on a NULL ensemble, a negative
255 * @p n_per_body or NULL @p ops.
256 *
257 * @collective Ranks holding no bodies must call it too.
258 * With one process no MPI call is made.
259 */
260int MFTLEnsembleReduceBodies(MFTL_Ensemble *ens, double *values, int n_per_body, const MFTL_BodyReduceOp *ops, MFTL_BodyReduceScope scope);

283/**
284 * @brief Per-body EXCLUSIVE prefix sum over the ranks that hold each body.
285 *
286 * Handing out global ids after a distributed remeshing phase needs a SCAN, not a
287 * reduction: two holders that both created vertices of one body need disjoint
288 * id ranges, so each needs the count created by the holders BEFORE it. "Before"
289 * is ascending rank -- the order the reduction folds in -- so the holders'
290 * ranges are disjoint and tile `[0, total)` exactly
291 * (`test_the_scan_tiles_every_body_exactly_once`). Same records, same
292 * certificate and same fallback (`MPI_Exscan` + `MPI_Allreduce` over a
293 * body-id-indexed buffer) as MFTLEnsembleReduceBodies().
294 *
295 * @param ens The ensemble.
296 * @param[in,out] values `[n_local_objects * n_per_body]` by local slot: this
297 * rank's contribution in; out, the sum over the holders of that
298 * body with a SMALLER rank. May be #MFTL_NULL only when this rank
299 * holds no bodies.
300 * @param[out] total `[n_local_objects * n_per_body]` sum over all holders, or
301 * #MFTL_NULL. Costs no extra collective.
302 * @param n_per_body Values per body, identical on every rank; 0 returns
303 * immediately.
304 * @param scope Route selection, identical on every rank.
305 * @return #MFTL_SUCCESS, or #MFTL_ERROR on a NULL ensemble or a negative
306 * @p n_per_body.
307 *
308 * @collective Ranks holding no bodies must call it too.

312/**
313 * @struct MFTL_BodyReduceStats
314 * @brief Counters of the per-body reductions and scans, by route taken.
315 *
316 * The route is invisible in the results (both are bit-identical by
317 * construction), so these counters are the only way to see a reduction pinned

327 long n_bytes; ///< Payload bytes moved by either route, sent plus received.
328} MFTL_BodyReduceStats;

360/**
361 * @brief Triangle geometry of every OWNED triangle plus per-body quality
362 * statistics, in one streaming pass per object and one reduction.
363 *
364 * Writes `tris.area`, `tris.normal`, `tris.center` for `[0, tris.n_local)` of
365 * every local object and fills each object's `quality` with the body-wide
366 * minimum, maximum and mean of the triangle area, the mean-ratio quality
367 * \f$q = 4\sqrt3 A/(a^2+b^2+c^2)\f$ and the squared edge length (means over
368 * owned triangles, resp. their half-edges, divided by global counts). The
369 * statistics come from the edges already in registers. Eleven values per body
370 * go through ONE MFTLEnsembleReduceBodies() call, so the payload scales with the
371 * bodies a rank holds, not with the ensemble. Statistics are PER BODY because
372 * that is what decides whether a particular body needs remeshing.
373 *
374 * @note Requires current derived connectivity (asserted); vertex motion does
375 * not invalidate it. GHOST triangles are not touched -- before a
376 * redistribution call MFTLComputeTriangleGeometry(obj, obj->tris.n).
377 * @note The statistics cost +90 % over geometry alone (a second divide), so on
378 * a non-periodic domain this is slower than MFTLComputeTriangleGeometry();
379 * call it for the statistics (docs/analysis.md §1.6).
380 *
381 * @param ensemble The ensemble.
382 *
383 * @collective Ranks holding no bodies must call it too.

444/**
445 * @brief Slot of rank @p r in `domain->neighbors`, by linear scan (at most 26).
446 *
447 * On grids with a single cut on a periodic axis `comm_graph` contains a
448 * self-loop, so asking for this rank itself is legitimate.
449 *
450 * @param domain The MPI/physical world.
451 * @param r A rank.
452 * @return The first slot holding @p r, or #MFTL_ERROR if @p r is not a graph

454 *
455 * @rank_local

457static inline int MFTLDomainNeighborIndex(const MFTL_Domain *domain, int r)
458{
459 for (int i = 0; i < domain->num_neighbors; ++i)
460 {
461 if (domain->neighbors[i] == r) return i;
462 }
463 return MFTL_ERROR;
464}
