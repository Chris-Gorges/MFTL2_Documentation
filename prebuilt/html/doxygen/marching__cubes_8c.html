Detailed Description

Marching cubes with a 256-case table GENERATED from one face rule, and an extractor that names every vertex by the lattice edge it lies on.

Author
Christian Gorges
Date
2026-09-25

Face rule. Walk a face's four corners counter-clockwise as seen from outside the cell; the sign changes at 0, 2 or 4 of its edges. Connect every crossing where the walk ENTERS the negative region to the next crossing where it LEAVES it. With two crossings that is the only segment; on an ambiguous face (negative corners on a diagonal) it cuts each negative corner off separately. The rule depends only on the face's four signs, and the neighbouring cell – walking the face in the opposite direction – produces the same segments with opposite orientation, so the surface cannot crack between cells. Every segment has the negative region on its right, so the chained loops are wound with normals from inside (negative) to outside.

A tabulated table assembled from symmetry classes and complements can resolve the same ambiguous face differently from its two sides – the classic marching-cubes hole. Generating every case from the face rule avoids it, and a typo in a hand-written row cannot exist.

Triangulating a loop. A loop may pass through one face twice; a fan from an arbitrary vertex could then create a triangle lying IN that face, which the neighbouring cell may duplicate. Each loop is fanned from an apex with no diagonal to a crossing on a shared face; the tests assert such an apex exists for every loop of every case (the centroid fallback is never used).

int MFTLExtractLevelSet ( const MFTL_SdfGrid * grid,
const int cell_lo[3],
const int cell_hi[3],
double snap,
MFTL_LevelSetSurface * out )

Marching cubes over the cells [cell_lo, cell_hi] of a grid window.

A cell is extracted iff its eight corners are in the window and none is MFTL_SDF_UNKNOWN. A vertex lies on each crossed lattice edge at the linear interpolant \(t = \phi_0/(\phi_0-\phi_1)\). Values closer to zero than snap * min(spacing) are pushed out to that distance (sign preserved, zero counted positive), so no vertex lands on a lattice node. Vertices on one lattice edge are shared between the cells of one call. On a periodic axis the range must not exceed one period.

Parameters
gridThe window.
cell_loFirst cell per axis, as a GLOBAL (unwrapped) lower-node index.
cell_hiLast cell per axis, inclusive.
snapRelative snap distance (e.g. 1e-2); 0 disables snapping (a node exactly at zero then still counts as positive).
[out]outAppended to; zero-initialise before the first call.
Returns
The number of triangles appended.
Rank-local:
Performs no MPI. Each rank operates on its own partition.

◆ MFTLBuildMeshFromLevelSet()

int MFTLBuildMeshFromLevelSet ( MFTL_Object * obj,
const MFTL_SdfGrid * grid,
double snap )

Triangulates the zero level set of a whole grid into an EMPTY object.

MFTLExtractLevelSet() over every cell of the window, positions wrapped into the object's domain, then MFTLBuildIndexedMesh(). Where the level set leaves the window the surface is open and its rim carries MFTL_FLAG_BOUNDARY; on a periodic axis a window of exactly one period closes it across the seam. Normals point to \(\phi > 0\). A level set that does not cross the window leaves the object empty (derived arrays marked current).

Parameters
objAn EMPTY object linked to a domain.
gridThe values.
snapRelative snap distance; see MFTLExtractLevelSet().
Returns
MFTL_SUCCESS, or MFTL_ERROR on invalid input.
Rank-local:
Performs no MPI. Each rank operates on its own partition.
