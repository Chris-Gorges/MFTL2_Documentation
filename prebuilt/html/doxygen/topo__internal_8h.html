Detailed Description

Internal interfaces of the topology-change module.

Author
Christian Gorges
Date
2026-09-25

THE FILES AND WHAT EACH MAY DO

topo_comm.c EVERY MPI call of the module, and nothing else. The same discipline as src/remeshing/remesh_comm.c: the algorithm files are pure local computation over data a collective handed them, which is what keeps the deadlock argument checkable by reading one file. topo_detect.c the pair predicate and the event list's canonical form topo_cluster.c lattice, clusters (union-find), extents, windows topo_reconstruct.c rasterisation, the bias, marching cubes, local meshes topo_split_bodies.c component labelling, ids, object construction topo_driver.c the two public entry points, in collective order

THE COLLECTIVE ORDER

Every rank executes the same sequence of collectives in the same order, whatever it holds. Nothing here returns early on a LOCAL count: a rank with no triangles of a cluster still enters every exchange with empty buffers.
