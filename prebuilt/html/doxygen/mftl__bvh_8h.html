Detailed Description

Linear BVH over triangle primitives, exact triangle-triangle predicates, and (distributed) object-object contact detection.

Author
Christian Gorges
Date
2026-08-16

The broad phase (a tree of float boxes) selects triangle pairs worth an exact test; the narrow phase (exact, double precision) decides whether they touch. Four decisions shape the module:

  1. A BVH is built over a primitive soup. Primitives [0, n_local_prims) are triangles of obj, [n_local_prims, n_prims) triangles of halo, a spatial-halo patch (an ordinary MFTL_Object, mftl_communication.h §6). Both are borrowed and const; the tree stores no geometry, and both kinds are read through MFTLGetTriangleCorners().
  2. Periodicity at two scales. Within an object, every primitive's corners are mutually unwrapped (minimum-image edges from corner 0), so a seam-straddling triangle has a tight box and its true centroid. Between objects, MFTL_IntersectObjects() traverses the pair once per periodic image of B (up to 27), each gated by one root-box test.
  3. The envelope scales with the body: tol = MAX(proximity_floor, proximity_factor * R), with R the body's radius; the same tol inflates the leaves and is the gap the narrow phase tests, so the broad phase never culls a pair the narrow phase would accept.
  4. A distributed contact is reported once, by the rank owning the A-side primitive: A trees contain owned triangles only, only B triangles travel, and pairs are ordered body_a < body_b by body id.

All of src/bvh/ is local; the one exchange (the spatial halo) belongs to the communication module. Theory: src/bvh/README.md.

◆ MFTL_GenerateLBVH()

MFTL_BVH * MFTL_GenerateLBVH ( const MFTL_Object * obj,
const MFTL_BVHBuildParams * params )

Builds a linear BVH over obj.

  1. One primitive per owned triangle (all triangles with include_ghosts).
  2. A 63-bit Morton key (MFTLMorton3D(), 21 bits per axis) of each primitive's seam-consistent, UNWRAPPED centroid, quantised with one common scale.
  3. A stable radix sort of (key, primitive) and a top-down split at the highest differing bit of the 95-bit key (key, index).
  4. Bottom-up box fit, then inflation by the resolved tolerance.

An object without primitives yields a valid EMPTY tree (not MFTL_NULL): a rank may hold nothing of a body and still receive a patch of it.

Parameters
objThe object; borrowed for the BVH's lifetime.
paramsMFTL_NULL for MFTL_BVHDefaultParams().
Returns
A new BVH (free with MFTL_DestroyBVH()), or MFTL_NULL if obj is MFTL_NULL.
Rank-local:
Performs no MPI. Each rank operates on its own partition. The tolerance uses this rank's radius until MFTL_BVHSetGlobalRadius() is called.

Reports every contacting primitive pair between two hierarchies.

For every periodic image of B whose shifted root box overlaps A's root, a dual-tree descent over an explicit stack of node pairs splits the node with the larger box volume; leaf-leaf candidates are collected into batches of 64 and passed to MFTL_TriTriProximity() at tolerance MAX(tol_A, tol_B). Only pairs with a LOCAL A-side primitive are tested, so a distributed run reports each contact once.

bvhBHierarchy over object B.
callbackInvoked per contacting pair; must not modify either object.
user_dataPassed through to callback.

Performs no MPI. Each rank operates on its own partition.

◆ MFTLEnsembleIntersectObjects()

int MFTLEnsembleIntersectObjects ( MFTL_Ensemble * ens,
const MFTL_BVHBuildParams * params,
IntersectionCallback callback,
void * user_data )

Contact detection for a whole ensemble: build, measure, exchange, attach, traverse, destroy.

  1. MFTL_GenerateLBVH() for every body this rank holds;
  2. MFTLSpatialHaloResolveRadii() and MFTL_BVHSetGlobalRadius() – the envelope is a fraction of the body, whose size is only known collectively;
  3. MFTLExtendSpatialHaloNearBodies() with those envelopes, which returns the patches AND the candidate body pairs (no all-pairs list is enumerated);
  4. MFTL_BVHSetHalo() per patched body; a body held nowhere here but patched gets a tree over a shared empty object;
  5. MFTL_IntersectObjects() per candidate pair (A = smaller body id). A self pair uses a second, tight (zero-envelope), patch-free A-side tree.

Cost: trees O(bodies held), traversals O(candidate pairs); two collective steps independent of the body count.

Parameters
ensThe ensemble.
paramsBuild parameters, or MFTL_NULL for the defaults.
callbackInvoked per contacting pair.
user_dataPassed through.
Returns
MFTL_SUCCESS, or MFTL_ERROR on invalid arguments.
Collective:
Must be called by every rank of the ensemble's communicator. Guarded by n_bodies_global (at least 2, or 1 with self_pairs). A contact between bodies whose holders are more than one cell apart is not found: the halo only ships along comm_graph.

◆ MFTL_Orient3D()

double MFTL_Orient3D ( const double pa[3],
const double pb[3],
const double pc[3],
const double pd[3] )

Robust orientation predicate: six times the signed volume of the tetrahedron (pa, pb, pc, pd), with an EXACT sign (Shewchuk 1997).

\[ \orient(\vect{a},\vect{b},\vect{c},\vect{d}) = (\vect{a}-\vect{d})\cdot\big[(\vect{b}-\vect{d})\times(\vect{c}-\vect{d})\big], \]

positive when pd lies below the plane through pa, pb, pc, i.e. when those appear counter-clockwise seen from above. Adaptive: the plain determinant plus a comparison against a rigorous error bound; exact expansion arithmetic only when that bound cannot certify the sign.

It is the one predicate whose SIGN decides an answer (Guigue-Devillers takes up to eight per pair); a wrong sign can report a clean miss for crossing triangles. Measured: 2.00x the plain determinant, at most 6.2 % of an MFTL_TriTriProximity() call; the plain form never misclassified in 20 000 samples at gaps >= 1e-12 of the body size and fails only at 1e-14..1e-16 (examples/orient3d_predicate_profile.c). Requires -ffp-contract=off.

Parameters
paFirst point of the reference plane.
pbSecond point.
pcThird point.
pdThe point being classified.
Returns
\(6V\); the SIGN is exact, the magnitude approximate.
