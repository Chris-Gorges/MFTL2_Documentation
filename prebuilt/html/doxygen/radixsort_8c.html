Detailed Description

LSD radix sort over 8-bit digits, for keys and for key/value pairs.

Author
Christian Gorges
Date
2025-08-12

Derived from Cameron Hart's zlib-licensed radix sort (licence notice below), specialised for MFTL: unified 32/64-bit key width, SoA key/value variants, signed 32-bit ordering, constant-digit pass skipping and a small-array cutoff.

◆ prefix_sum_histograms()

uint32_t prefix_sum_histograms ( uint32_t *restrict hist,
uint32_t passes,
size_t n,
uint64_t first_key,
bool signed_msb )
static

Turns each pass's counts into starting OFFSETS, in place.

Two refinements, both touching only the \(256 \times\) passes counters:

  • Constant digits are skipped. If the bucket of first_key's digit holds all n keys, the digit is constant and its pass is the identity. Dense global ids leave the top bytes constant, so typically half the passes of a 32-bit id sort vanish.
  • Signed order. For the most significant pass of a signed key the offsets are accumulated in the rotated bucket order 0x80..0xFF, 0x00..0x7F, which places negative keys first without modifying any key.
Parameters
histpasses * HIST_SIZE counters, converted from counts to exclusive prefix sums.
passesNumber of digit passes.
nNumber of keys, i.e. the total each histogram sums to.
first_keyAny one key; its digits identify the constant buckets.
signed_msbtrue for signed 32-bit keys: the top pass's prefix sum starts at bucket 128 and wraps to 0, which places negative keys first without ever flipping a bit.
Returns
Bit mask of the passes that must actually run.

void MFTLRadixSort32 ( int * keys_in,
int * keys_temp,
int size )

Low-level key-only sort: 32-bit signed keys, caller-managed temp buffer.

The result is always left in keys_in, whatever the internal pass count turns out to be. keys_temp is scratch space and holds an unspecified permutation of the input afterwards.

Parameters
keys_inKeys to sort in place. Must hold size elements.
keys_tempScratch buffer of at least size elements. Only read when size exceeds the internal small-array cutoff, but must always be valid.
sizeNumber of keys. Values < 2 are a no-op.
