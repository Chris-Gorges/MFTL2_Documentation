Detailed Description

Macros and plain-C helpers that know nothing about MFTL types.

Everything here is a leaf of the include graph: these headers include only each other and the C standard library, so they can be pulled into any translation unit without dragging the mesh data model along.

The layer answers four questions and nothing else:

Header Question
mftl_constants.h What is a tolerance, what is a cache line, what does an assertion do in Release?
mftl_memory.h How is memory obtained, and how does one allocation become many aligned sub-arrays?
mftl_vectoroperations.h What is a normalised 3-vector?
mftl_arrayfunctions.h How is a flat integer array sorted and deduplicated?
