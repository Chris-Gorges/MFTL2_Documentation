Detailed Description

The icosphere: an icosahedron, N rounds of 1-to-4 midpoint subdivision, one final projection onto the sphere.

Author
Christian Gorges
Date
2026-08-14

Subdivision emits an indexed triangle list and lets MFTLBuildTopologyFromIndexList() build the topology, so there is one half-edge construction loop in the library. Old vertices keep their indices (midpoints are appended), so the vertex pool grows in place.

int tessellate_sphere ( MFTL_Object * object)

One level of 1-to-4 subdivision, in place. 

 v2
/  \

m2 – m1 / \ / \ v0 – m0 – v1

Each edge's midpoint (the plain average, NOT projected: projection happens once, after the last level) is created once: midpoint_map[h] is written for a half-edge and its twin together, so the second triangle finds it by a direct array read – "the other side of this edge" is already an index, no hash map needed. The sub-triangles keep their parent's rotational order, which propagates the outward winding. Requires a closed mesh.

Parameters
objectThe mesh; every triangle becomes four.
Returns
MFTL_SUCCESS, or MFTL_ERROR on an open mesh or a topology failure.

◆ MFTLGenerateSphere()

int MFTLGenerateSphere ( MFTL_Object * object,
double center[3],
double radius,
int refinements )

Generates an icosphere: a regular icosahedron, refinements rounds of 1-to-4 midpoint subdivision, then one central projection onto the sphere of radius radius about center.

On rank 0: \(V = 10\cdot4^r+2\) vertices, \(F = 20\cdot4^r\) triangles; other ranks get an empty object. Face normals point OUTWARD at every level (the face table is counter-clockwise seen from outside and subdivision preserves the parent's rotation), which fixes the sign of the enclosed volume, of surface tension and of the indicator function. Mean-ratio quality is at least 0.974 (mean 0.997) at every level; triangle areas vary by up to about a factor 2. Positions are wrapped into a periodic domain, and triangle geometry is current on return. The result is in subdivision order; MFTLObjectReorderMorton() gives spatial locality.

Parameters
objectThe object to generate into; must already be in an ensemble.
centerSphere centre.
radiusSphere radius, >= 0.
refinementsSubdivision levels, >= 0 (0: the bare icosahedron).
Returns
MFTL_SUCCESS, or MFTL_ERROR on invalid arguments.
Collective:
Must be called by every rank of the ensemble's communicator. One broadcast (id counters) and one reduction (global counts).
