Detailed Description

Convenience umbrella header.

Author
Christian Gorges
Date
2026-08-14

Includes every public MFTL header so that application code can get the whole library with a single include. Library sources should NOT use this – each .c file includes its own module header first, plus exactly the module headers it actually needs. That keeps the dependency graph visible and acyclic:

layer 0 mftl_constants.h mftl_memory.h mftl_vectoroperations.h mftl_arrayfunctions.h layer 1 mftl_types.h layer 2 mftl_topology.h mftl_geometry.h layer 3 mftl_object.h mftl_ensemble.h mftl_meshgen.h mftl_communication.h mftl_io.h mftl_remeshing.h mftl_bvh.h mftl_topology_change.h layer 4 mftl_core.h (this file)

A header may only include headers from a strictly lower layer.
