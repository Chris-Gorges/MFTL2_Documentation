1/**
2 * @file remesh_comm.h
3 * @author Christian Gorges
4 * @date 2026-08-17
5 * @ingroup mftl_remeshing
6 *
7 * @brief Every MPI call the remeshing module makes, and nothing else.
8 *
9 * ## Why this file exists
10 *
11 * Of every source in src/remeshing only remesh_comm.c may call MPI
12 * (`test_remeshing_mpi_is_confined`, a build-time source check); the operators,
13 * the smoother, the compaction and both drivers are local computation over a
14 * partition arranged here. The rule exists because the first distributed
15 * version grew the production primitives instead: a cut-plane offset inside
16 * MFTLGetOwnerProc() (1.70x slower `compute_owners`, which runs per entity per
17 * timestep) and a "new global id" field in the per-timestep ghost exchange.
18 * Both were reverted in favour of this file plus one seam in redistribution,
19 * #MFTL_OwnerMap (NULL on the production path).
20 *
21 * ## What is here, and how each scales
22 *
23 * MFTLRemeshMigrateShifted 26-neighbour redistribution under moved planes;
24 * skipped (one int, LOR) when it is the identity.
25 * MFTLRemeshMigrateToRanks 26-neighbour while bodies fit a rank box;
26 * redistribution falls back to its global path
27 * otherwise.
28 * MFTLRemeshSumInts Allreduce of 3 ints per phase (certificate).
29 * MFTLRemeshSyncGhostIds 3 neighbourhood collectives, 4 bytes per ghost
30 * vertex, once per pass; global fallback when a
31 * ghost's owner is not a graph neighbour (normal
32 * under coarsening).
33 * MFTLRemeshMeasureBodies per-body holder reductions (9 values, then 1)
34 * plus one scalar MPI_MAX; once per pass.
35 * MFTLRemeshAgree* small fixed-size Allreduces (the parameter block
36 * once per call, profile, frozen counts, balancer
37 * scalars, Debug checks).
38 * MFTLRemeshNeighbor* the balancer's one-hop exchanges: O(local
39 * bodies) or O(1) per neighbour, never sized by
40 * n_bodies_global.
41 *
42 * A shifted migration moves far more than the band: between shifts a and b an
43 * entity changes owner on axis k iff its coordinate lies in [a_k, b_k) modulo
44 * h_k, so the moved fraction is 1 - PROD_k (1 - |b_k - a_k| / h_k): 87.5 % for
45 * (0,0,0) -> (1,1,1), 50 % for one axis, 75 % for two
46 * (MFTL_RemeshStats::n_entities_migrated). The band is what is FROZEN, not what
47 * moves. Not everything here is O(degree) either: MFTLRemeshSyncGhostIds() and
48 * the redistribution behind every migration allocate arrays sized by nproc,
49 * which matters at P in the thousands times the phase count.
50 */

64/**
65 * @brief The per-axis offset of the cut planes for one phase of the schedule.
66 *
67 * @p phase entries are 0 or 1; the eight combinations are MFTL_REMESH_PHASES.
68 * An axis with a single cut has no interior plane to move, and shifting it would
69 * only rotate the one cell against the periodic seam -- migration for no gain in
70 * coverage -- so it is left alone.
71 *
72 * Every rank must call this with the same @p phase before the migration that
73 * follows. It contains no MPI, so nothing detects a disagreement, and a
74 * disagreement makes ownership AMBIGUOUS rather than merely suboptimal. What
75 * keeps it true is that the phase index comes from a compile-time table and a
76 * loop counter, never from data.
77 *
78 * @param domain The MPI/physical world.
79 * @param group Per-axis coarsening factors, from MFTLRemeshCoarseningFactors().
80 * @param phase Per-axis phase entry, 0 or 1.
81 * @param[out] out Per-axis cut-plane offset in domain length units.
82 */
83static inline void MFTLRemeshPhaseShift(const MFTL_Domain *domain, const int group[3], const double phase[3], double out[3])
84{
85 for (int k = 0; k < 3; ++k)
86 {
87 const int g = (group && group[k] > 1) ? group[k] : 1;
88
89 /* The planes that move are the COARSE ones, so the box to halve is g cells
90 * wide -- and an axis with fewer than two coarse cells has no interior plane
91 * at all, which is the same test as before with `cuts` replaced by
92 * `cuts / g`. Getting this wrong is silent: the shift would be half a FINE
93 * cell, the band would not clear it, and the schedule would simply stop
94 * covering while every structural check still passed. */
95 const int n_groups = domain->cuts[k] / g;
96 const double h = (n_groups > 1) ? (double) g * domain->domain_size[k] / (double) domain->cuts[k] : 0.0;
97 out[k] = phase[k] * 0.5 * h;
98 }
99}

101/**
102 * @brief The rank owning @p pos when every cut plane of axis k sits at
103 * `global_min[k] + shift[k] + j*h_k`.
104 *
105 * MFTLGetOwnerProc with the planes moved, and the shift is exactly what forces
106 * the extra branch. Without it the argument of the truncation is non-negative
107 * for any wrapped position, so `(int)` IS `floor` and clamping is the same as
108 * wrapping. With a shift of up to h/2 the argument reaches -0.5, where `(int)`
109 * truncates TOWARDS ZERO and would report cell 0 for a point belonging to cell
110 * `cuts-1` on the far side of the seam. That is a silent half-cell of
111 * misattributed ownership right at the seam -- which is precisely where the
112 * schedule is trying to put the frozen band.
113 *
114 * The bias by `cuts` makes the truncation a floor again for one add and one
115 * predicated subtract. The non-periodic path keeps the clamp, because there a
116 * negative argument really does mean "off the end of the grid".
117 *
118 * @p pos must be WRAPPED into the domain, exactly as for MFTLGetOwnerProc.
119 *
120 * @param domain The MPI/physical world.
121 * @param k Axis, 0..2.
122 * @param shift Per-axis cut-plane offset.
123 * @param pos A position, already wrapped into the domain.
124 * @return The FINE cell index along axis @p k, clamped to `[0, cuts[k])`.
125 */
126static inline int MFTLRemeshFineCell(const MFTL_Domain *domain, int k, const double shift[3], const double pos[3])
127{
128 const int cuts = domain->cuts[k];
129 const double s = (pos[k] - domain->global_min[k] - shift[k]) * domain->grid_factors[k];
130
131 int i;
132 if (domain->is_periodic[k])
133 {
134 /* s lies in [-0.5, cuts) for any wrapped position and any shift in
135 * [0, h/2], so a single bias-and-subtract is a complete modulo. */
136 i = (int) (s + (double) cuts);
137 if (i >= cuts) i -= cuts;
138 }
139 else
140 {
141 i = (int) s;
142 }
143
144 if (i < 0) i = 0;
145 if (i >= cuts) i = cuts - 1;
146 return i;
147}

149/**
150 * @brief MFTLGetOwnerProc() evaluated against cut planes offset by @p shift.
151 *
152 * @param domain The MPI/physical world.
153 * @param shift Per-axis cut-plane offset from MFTLRemeshPhaseShift().
154 * @param pos A position, already wrapped into the domain.
155 * @return The rank owning @p pos under the shifted decomposition.
156 *
157 * @warning A shifted plane needs a FLOOR, not a truncation. On a periodic axis
158 * the argument reaches \f$-0.5\f$, where `(int)` truncates *towards
159 * zero* and attributes the sliver at the domain minimum to cell 0
160 * instead of to cell `cuts-1` across the seam. The wrong rule is still
161 * a consistent rule -- every rank computes the same answer and every
162 * structural invariant holds -- so the only symptom is that the SEAM
163 * PLANE NEVER MOVES and the entities on it are frozen in every phase.
164 */
165static inline int MFTLRemeshOwnerProc(const MFTL_Domain *domain, const double shift[3], const double pos[3])
166{
167 const int c0 = MFTLRemeshFineCell(domain, 0, shift, pos);
168 const int c1 = MFTLRemeshFineCell(domain, 1, shift, pos);
169 const int c2 = MFTLRemeshFineCell(domain, 2, shift, pos);
170 return domain->rank_map[c0 + c1 * domain->cuts[0] + c2 * domain->cuts[0] * domain->cuts[1]];
171}

173/**
174 * @brief MFTLRemeshOwnerProc() on a decomposition COARSENED by @p group per axis.
175 *
176 * The shift schedule needs \f$h > 4\delta\f$; when more ranks shrink h below
177 * that, bands along the cut planes are silently never remeshed. A coarser
178 * decomposition needs no second communicator: redistribution accepts any
179 * destination per entity (#MFTL_OwnerMap), so coarsening is just a different
180 * owner function -- fine cell, integer-divided by the group size, mapped to a
181 * representative fine cell's rank. Every rank still enters every collective;
182 * non-representatives receive nothing. The freeze rule (`index >= n_local`) and
183 * the covering argument transfer with \f$H_k = g_k h_k\f$, and the closing
184 * MFTLRedistribute() restores the fine partition.
185 *
186 * Cost: \f$1/(g_0g_1g_2)\f$ of the ranks do all the sweeping, and destinations
187 * leave the 26-neighbourhood, so redistribution and MFTLRemeshSyncGhostIds()
188 * take their global paths. Per-axis factors keep the loss to the axes that need
189 * it.
190 *
191 * @param domain The MPI/physical world.
192 * @param group Per-axis coarsening factors, each >= 1; {1,1,1} is bit-for-bit
193 * MFTLRemeshOwnerProc().
194 * @param shift Per-axis cut-plane offset.
195 * @param pos A position, already wrapped into the domain.
196 * @return The rank owning @p pos under the coarsened, shifted decomposition;
197 * all ranks of a group map to the same one.
198 */
199static inline int MFTLRemeshCoarseOwnerProc(const MFTL_Domain *domain, const int group[3], const double shift[3], const double pos[3])
200{
201 int c[3];
202 for (int k = 0; k < 3; ++k)
203 {
204 /* The fine cell comes from the SAME function the uncoarsened rule uses. Two
205 * copies of the periodic floor is exactly the kind of duplication that
206 * drifts, and the thing it would drift away from is a silent half-cell of
207 * misattributed ownership at the seam. */
208 const int i = MFTLRemeshFineCell(domain, k, shift, pos);
209 const int cuts = domain->cuts[k];
210 const int g = (group[k] > 1) ? group[k] : 1;
211
212 /* THE REMAINDER GOES INTO THE LAST GROUP, never into a short one of its own.
213 * A short group is narrower than the others, so its H is smaller, and if it
214 * falls below 4*delta its planes are exactly the ones that never move -- the
215 * permanently frozen seam this whole path exists to remove, reintroduced at
216 * the far end of every axis. Absorbing the remainder makes the last group up
217 * to 2g-1 cells wide, which is only ever wider than it needs to be. */
218 const int n_groups = (cuts >= g) ? cuts / g : 1;
219 int grp = i / g;
220 if (grp >= n_groups) grp = n_groups - 1;
221
222 c[k] = grp * g;
223 }
224 return domain->rank_map[c[0] + c[1] * domain->cuts[0] + c[2] * domain->cuts[0] * domain->cuts[1]];
225}

227/**
228 * @brief Shrinks @p group until it merges at most @p cap ranks per group.
229 *
230 * Shared rather than duplicated because BOTH paths that coarsen have to apply
231 * the same cap: the spanning driver caps the factors it partitions by, and the
232 * dispersed strategy caps the factors it uses as a yardstick for "is a body
233 * small enough for one rank". Two copies of this loop would eventually differ,
234 * and the symptom would be the chooser electing DISPERSED on a body the driver
235 * then rejects -- one wasted migration and a fall back to the spanning path,
236 * reported only as `n_bodies_not_centred`.
237 *
238 * The largest factor is shrunk first, which keeps the merged boxes as close to
239 * cubic as the cap allows. A cap below 1 is ignored; @p cap <= 1 means no cap.
240 *
241 * @param[in,out] group [3] per-axis factors, each >= 1.
242 * @param cap Maximum `group[0]*group[1]*group[2]`. <= 1 is a no-op.
243 * @rank_local Pure arithmetic; every rank must call it with the same inputs.
244 */
245static inline void MFTLRemeshCapGroups(int group[3], int cap)
246{
247 if (cap <= 1) return;
248
249 while (group[0] * group[1] * group[2] > cap)
250 {
251 int worst = 0;
252 for (int k = 1; k < 3; ++k)
253 {
254 if (group[k] > group[worst]) worst = k;
255 }
256 if (group[worst] <= 1) break;
257 group[worst]--;
258 }
259}

336/**
337 * @brief Redistributes the ensemble so that local body `o` lands wholly on `dest[o]`.
338 *
339 * The object-centering migration of the dispersed strategy: every entity of a
340 * body -- owned and ghost, vertex and triangle -- is given the same

397/**
398 * @brief Refuses, on EVERY rank, a parameter block that is invalid on any rank or
399 * not identical on all of them.
400 *
401 * Nothing in a distributed pass communicates the parameters: every rank is
402 * assumed to hold the same block. Some fields decide the sequence of
403 * collectives (`parallel_strategy`, `parallel_phase_budget`, the coarsening
404 * controls), the rest decide what happens to shared entities. Two realistic
405 * violations, neither with a symptom of its own:
406 *
407 * - **A band that is invalid on some ranks only.** The usual cause is
408 * MFTLMeanEdgeLength() (LOCAL) on a distributed mesh: 0 on a rank holding no
409 * triangle of the body. A per-rank refusal returns on that rank and leaves the
410 * others in the next collective, which is a hang in Release.
411 * - **Blocks that differ between ranks.** Different collective sequences hang;
412 * different decisions on shared entities give an inconsistent mesh.
413 *
414 * One `MPI_Allreduce(MIN)` over every field, every negated field and the local
415 * band verdict gives each rank the extremes of every field and the worst
416 * verdict, so all ranks reach the same answer; a refusal is useful only if it
417 * is unanimous. The band is valid when
418 * \f$0 \le \ell_{\min} \le \ell_{\max}\f$ and \f$\ell_{\max} > 0\f$
419 * (NaN fails). Fields must agree bitwise. Rank 0 prints the reason on stderr.
420 *
421 * @param domain The MPI/physical world.
422 * @param params This rank's parameter block.
423 * @param caller Name of the public entry point, for the diagnostic.
424 * @return #MFTL_SUCCESS on every rank, or #MFTL_ERROR on every rank.
425 * @collective One Allreduce of 49 doubles; at `nproc == 1` only the band test.
426 */
427int MFTLRemeshAgreeParams(const MFTL_Domain *domain, const MFTL_RemeshParameters *params, const char *caller);

487/**
488 * @brief Tells every ghost vertex the NEW global id its owner has just given it.
489 *
490 * Parallel remeshing makes the global ids sparse -- splits hand out ids,
491 * collapses retire them -- and has to re-densify them, but a rank may only
492 * renumber what it owns. This closes the gap for the ghosts.
493 *
494 * ── Why a renumbering cannot simply be followed by a redistribution ────────
495 *
496 * Because redistribution KEEPS ghost vertices. A ghost is retained as a corner
497 * of a kept owned triangle, and arrivals are de-duplicated against the kept set
498 * BY GLOBAL ID. A kept ghost still carrying its pre-renumbering id therefore
499 * fails to match the authoritative copy its owner now sends, both survive, and
500 * the twin rebuild -- which pairs by vertex SLOT -- tears the surface along the
501 * partition boundary. Ghost TRIANGLES have no such problem: they are dropped and
502 * re-received every time, which is why only the vertices need this.
503 *
504 * ── Why it is here and not a third field of MFTLUpdateGhostPositions ───────
505 *
506 * It asks the same question of the same set, so sharing that schedule was
507 * tempting and was in fact tried. The cost landed in the wrong place: the shared
508 * function acquired a payload discriminator that every per-timestep position
509 * sync then evaluated once per ghost vertex, to serve a call made once per
510 * remesh. Written separately it is also strictly cheaper on the wire -- 4 bytes
511 * per ghost instead of the 32-byte MFTL_GhostUpdatePayload, and no registered
512 * MPI datatype at all.
513 *
514 * @param ens The ensemble.
515 * @param vertex_gid_base `[ens->n_local_objects]` first new vertex id this rank was
516 * allotted per body, or #MFTL_NULL when the ids did not move.
517 * @return #MFTL_SUCCESS, or #MFTL_ERROR if the exchange failed.
518 */
519int MFTLRemeshSyncGhostIds(MFTL_Ensemble *ens, const int *vertex_gid_base);

522 * 4. Neighbourhood exchange -- the three shapes the dispersed balancer needs

524 * Each moves a payload proportional to `num_neighbors` (<= 26) and to what THIS
525 * rank holds; none can carry an array indexed by body id or by rank.
526 *
527 * The self-loop: `domain->neighbors` comes from the 26 cell OFFSETS, so on a
528 * grid with a single cut on a periodic axis (shapes {2,1,1}, {2,2,1}) two
529 * offsets wrap onto this rank and a gather returns this rank's own block. A
530 * caller that also folds in its own contribution locally must skip the slot
531 * `MFTLDomainNeighborIndex(domain, domain->rank)` reports, or every SUM doubles.
532 * ═══════════════════════════════════════════════════════════════════════════ */
