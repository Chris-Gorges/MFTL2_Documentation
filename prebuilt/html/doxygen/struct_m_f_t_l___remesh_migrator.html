Detailed Description

Reusable scratch for the owner maps of a remeshing pass.

A spanning pass migrates up to parallel_phase_budget times, each needing one destination per entity; the arena grows geometrically and is reused so later migrations do not pay first-touch page faults again. It belongs to the caller, not to MFTL_Domain, which is read-only during a redistribution. Both arrays are sized by what this rank holds; maps is indexed by local slot, because its only reader walks the same list in the same order.
