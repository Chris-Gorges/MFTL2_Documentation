Author

Not a public header: nothing outside src/communication/ may include it, and nothing here is exported. It holds the two data structures that both the redistribution and the ghost synchronisation need.

void cs_alloc ( size_t bytes)
inlinestatic

Records an allocation of bytes into the redistribution counters.

The byte count is what was REQUESTED, summed over the run – not a peak and not what the allocator actually mapped. It is a churn measure: the question it answers is how much a persistent workspace would stop re-requesting.

◆ gt_hash()

unsigned gt_hash ( int gid)
inlinestatic

Scatters a global id over a sparse table's index space (multiplicative avalanche hash).

The identity index clusters badly: a partition's ids are many dense runs that alias under the mask, and linear probing then degrades to quadratic insertion (measured 127 ms against 0.76 ms on a 327 680-triangle body).

Parameters
gidThe global id.
Returns
A well-mixed 32-bit value.
