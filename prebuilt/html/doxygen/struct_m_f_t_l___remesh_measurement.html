Detailed Description

What MFTLRemeshMeasureBodies() produced, BY LOCAL SLOT, plus the one number that has to be ensemble-wide.

Row o describes ens->local_objects[o] at the moment the measurement was taken, so it is invalidated by anything that changes the local list – which in this module means the first migration. Every consumer reads it before one.

r_max is separate because it is the only quantity here that every rank must agree about: the strategy ratio and the dispersed admission test are both taken against it, and two ranks answering differently is two ranks entering different drivers.

◆ lowest_holder

double* lowest_holder

[n_local] lowest-numbered rank holding each body.

lowest_holder[o] == domain->rank designates THIS rank as the one that may count body o in a sum over ranks. Every holder reduces to the same radius and the same weight, so without it a body held by four ranks is counted four times – which is what made the dispersed driver report "4 of 1 bodies are wider than a rank box".
