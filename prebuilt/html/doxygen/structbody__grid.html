Detailed Description

A uniform grid over the domain, one bucket list per cell.

Cells are at least as wide as the reach on every axis, which makes a 27-cell query exhaustive. The cell count is capped at 4 x items + 64 so a domain much larger than the bodies does not allocate proportionally to the domain.
