Detailed Description

What a migration actually did, for the profile and for the tests.

performed is false when the requested placement turned out to be the one the mesh already had, so the redistribution was skipped – which is the normal case for phase 0 of the schedule. It is a GLOBAL verdict: redistribution is collective, so either every rank skips or none does.
