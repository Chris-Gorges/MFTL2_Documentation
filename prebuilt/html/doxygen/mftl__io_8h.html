Detailed Description

Mesh output in VTK formats: a serial legacy debug dump and a parallel VTK XML (.vtu) writer.

Author
Christian Gorges
Date
2026-08-14

Nothing is read back by the library. Four decisions define MFTLWriteVtu():

  1. Raw binary by default. Decimal formatting of a double costs about 100 ns and ~17 bytes, so an ASCII writer is bound by printf, not by the disk; the appended raw section is a memcpy (23-32x faster, docs/analysis.md §3). ASCII is kept for inspection.
  2. Two file layouts. One piece per rank plus a .pvtu index (no contention, but P+1 files per dump – what overloads a parallel file system's metadata server first), or one shared file written collectively with MPI-IO. On one local SSD the per-rank layout was faster (the shared file: 1.0x at P = 1, 0.45x at P = 4); re-measure on the target system.
  3. Only owned entities are written. A ghost is a copy of a triangle another rank owns; writing it would count every halo triangle once per holder and bias every integral a visualisation tool computes (10-30 % in a typical run). include_ghosts exists for inspecting the halo.
  4. Periodic unwrapping at write time. A triangle straddling a periodic face gets three private points at its unwrapped corners; the mesh in memory is untouched.

Theory: src/io/README.md.

enum MFTL_VtkEncoding

How the numbers are encoded in a .vtu file.

Enumerator
MFTL_VTK_BINARY 

Raw binary in an appended section, in the host byte order (declared in the header). The default: 23-32x faster to write than ASCII and about half the size; read natively by ParaView and VisIt.

MFTL_VTK_ASCII 

Decimal text inside the DataArray elements: human-readable and diffable. Not available with MFTL_IO_SINGLE_FILE.

◆ MFTLWriteVtk()

int MFTLWriteVtk ( const MFTL_Object * object,
const char * base_filename )

Writes the calling rank's pool of one object to a legacy ASCII .vtk file: the raw debug dump.

Every entity the rank holds, ghosts included, with no filtering, no periodic unwrapping and no communication. It also writes VertexOwner, TriangleOwner, verts.normal and tris.area UNVALIDATED – its contract is to show what is in memory, including arrays a redistribution left undefined.

Strictly single-rank: several ranks writing the same path race. Call it from one rank, or give every rank its own name.

Parameters
objectThe object (valid topology required).
base_filenameBase path; ".vtk" is appended.
Returns
MFTL_SUCCESS, or MFTL_ERROR on a NULL argument or an I/O failure.

Legacy POLYDATA layout written here: 

POINTS <nv> double
<x> <y> <z>                    x nv
POLYGONS <nt> <4*nt>
3 <v0> <v1> <v2>               x nt

The second POLYGONS field is the total integer count of the block (four per record, the leading 3 included). Pool indices are file indices.

◆ MFTLWriteVtu()

int MFTLWriteVtu ( MFTL_Ensemble * ensemble,
const char * filename_prefix,
const MFTL_VtkOptions * options )

Writes every local object of an ensemble as one VTK XML unstructured grid (all bodies in one point/cell list per piece).

Points are the vertices referenced by the written triangles (owned triangles may reference ghost vertices), plus three private points per triangle that straddles a periodic face; a seam vertex is therefore written by every rank with a triangle on it. Cells carry TriangleOwner, BodyID and optionally TriangleGID; points VertexOwner and optionally VertexGID. Uses compact connectivity when current, the half-edge records otherwise; no geometry precondition.

  • MFTL_IO_FILE_PER_RANK writes <prefix>_%05d.vtu per rank and <prefix>.pvtu on rank 0.
  • MFTL_IO_SINGLE_FILE writes one <prefix>.vtu with one Piece: one non-blocking MPI_Exscan + MPI_Allreduce pair places every block, rank 0 writes header, length prefixes and footer, and every rank writes its slice of each block with MPI_File_write_at_all (enabling two-phase collective buffering). The file is truncated to its exact size. Requires MFTL_VTK_BINARY and at most \(2^{31}-1\) points and \((2^{31}-1)/3\) cells (Int32 connectivity and offsets).
Parameters
ensembleThe ensemble; zero objects yield a valid empty dataset.
filename_prefixBase path/name; suffixes are appended.
optionsMFTL_NULL for MFTLVtkDefaults().
Returns
MFTL_SUCCESS if every rank succeeded, MFTL_ERROR otherwise – the same value on every rank.
Collective:
Must be called by every rank of the ensemble's communicator. In both layouts (the return code is reduced).
