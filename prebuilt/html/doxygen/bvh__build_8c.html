◆ prefix_len()

int prefix_len ( const uint64_t *restrict keys,
int i,
int j )
inlinestatic

Common-prefix length of the 95-bit keys (Morton code, index) at sorted slots i and j.

A radix split needs UNIQUE keys: equal codes (two triangles in one Morton cell – common at fine resolution) would never split. Appending the slot index (ascending, since the array is sorted) makes the keys unique without another sort and bounds the tree depth by 95 (Karras 2012): \(\delta = \clz_{64}(Z_i \oplus Z_j)\) if the codes differ, else \(64 + \clz_{32}(i \oplus j)\).

Parameters
keysThe sorted Morton codes.
iFirst slot.
jSecond slot; must differ from i.
Returns
Common prefix length in bits.

Populates node node_idx and, recursively, its subtree.

The split is the last slot still sharing a longer prefix with the first than the range's common prefix, found by binary search ( \(\delta(f,\cdot)\) is non-increasing over sorted keys). The children are therefore separated by a dyadic plane of the Morton grid. Recursion depth is bounded by 95.

◆ MFTLBVHRefit()

void MFTLBVHRefit ( MFTL_BVH * bvh)

Refits every node's box and resolves the tolerance, in three linear passes with no recursion.

  1. Reverse scan over [nodes_used-1 .. 0]: leaves fit their primitives, internal nodes merge their children (every child index exceeds its parent's, so children are always visited first).
  2. bounding_radius from the root box; tolerance from it (or from radius_hint).
  3. Forward scan inflating every node by the tolerance – valid because a uniform inflation commutes with the min/max merge.

Shared by MFTL_GenerateLBVH() and MFTL_RefitLBVH() (test_refit_only_matches_full_rebuild).

Parameters
bvhThe hierarchy; boxes, bounding_radius and tolerance rewritten.

◆ MFTL_RefitLBVH()

int MFTL_RefitLBVH ( MFTL_BVH * bvh,
const MFTL_Object * obj )

Refits the boxes after the vertices moved; tree and order are kept.

Skips centroids, keys, sort and split; the refit is a reverse linear scan over the nodes (every child index exceeds its parent's). The tree quality degrades as the mesh deforms away from the configuration it was sorted for: rebuild after redistribution, remeshing or large deformation. Halo primitives keep the positions they arrived with.

Parameters
bvhThe hierarchy, refitted in place.
objThe object it was built from (asserted).
Returns
MFTL_SUCCESS, or MFTL_ERROR – a supported outcome, not asserted – when the primitive counts changed (the triangulation was modified); the BVH is then untouched and the caller rebuilds.
Rank-local:
Performs no MPI. Each rank operates on its own partition.

◆ MFTL_GenerateLBVH()

MFTL_BVH * MFTL_GenerateLBVH ( const MFTL_Object * obj,
const MFTL_BVHBuildParams * params )

Builds a linear BVH over obj.

  1. One primitive per owned triangle (all triangles with include_ghosts).
  2. A 63-bit Morton key (MFTLMorton3D(), 21 bits per axis) of each primitive's seam-consistent, UNWRAPPED centroid, quantised with one common scale.
  3. A stable radix sort of (key, primitive) and a top-down split at the highest differing bit of the 95-bit key (key, index).
  4. Bottom-up box fit, then inflation by the resolved tolerance.

An object without primitives yields a valid EMPTY tree (not MFTL_NULL): a rank may hold nothing of a body and still receive a patch of it.

Parameters
objThe object; borrowed for the BVH's lifetime.
paramsMFTL_NULL for MFTL_BVHDefaultParams().
Returns
A new BVH (free with MFTL_DestroyBVH()), or MFTL_NULL if obj is MFTL_NULL.
Rank-local:
Performs no MPI. Each rank operates on its own partition. The tolerance uses this rank's radius until MFTL_BVHSetGlobalRadius() is called.
