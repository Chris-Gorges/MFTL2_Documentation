Detailed Description

Allocation policy, cache-line-aligned pool blocks, and array growth.

Author
Christian Gorges
Date
2026-08-14

Layer 0. Two kinds of storage, handled differently:

  • Pool blocks (the vertex and triangle pools of an MFTL_Object). The AoS records and every SoA array of a pool describe the same entities, so they must always have the same capacity. A pool is therefore ONE allocation, cut into cache-line-aligned sub-arrays by MFTLLayoutAdd(): one pointer to free, one capacity, and no way to grow half of it. Only src/object/object.c calls MFTLLayoutAdd().
  • Independent arrays (object lists, per-neighbour buffers, algorithm scratch) use MFTLMallocOrDie() / MFTLCallocOrDie() / MFTLReallocOrDie() and the growth macros MFTL_ENSURE_CAPACITY and MFTL_RESERVE_ADDITIONAL.

Allocation failure is fatal everywhere: in an MPI job an out-of-memory rank cannot recover, and a NULL buffer carried on corrupts data far from the cause.

Geometric growth (×2). For incremental appends inside a loop.

Grows only when *count + needed exceeds *capacity, following MFTLGrowCapacity()'s doubling schedule, so \(n\) appends cost \(O(\log n)\) reallocations.

◆ MFTLLayoutAdd()

size_t MFTLLayoutAdd ( size_t * cursor,
size_t count,
size_t elem_size )
inlinestatic

Reserves one sub-array inside a pool block and returns its byte offset.

Call it once per field, in order, starting from a zeroed cursor; afterwards cursor holds the total block size: \(o_0 = 0,\; o_{i+1} = L\lceil (o_i + n_i s_i)/L \rceil\) with \(L = \) MFTL_CACHE_LINE. 

size_t cursor = 0;
const size_t o_rec = MFTLLayoutAdd(&cursor, cap,     sizeof(MFTL_Vertex));
const size_t o_pos = MFTLLayoutAdd(&cursor, 3 * cap, sizeof(double));
...
unsigned char *block = MFTLAlignedAllocOrDie(cursor, "vertex pool");

Because the capacity is a property of the block, "the AoS grew but an SoA array did not" cannot be expressed.

Parameters
cursorRunning block size in bytes, updated in place. Start at 0.
countNumber of elements in this sub-array.
elem_sizeSize of one element in bytes.
Returns
Byte offset of the sub-array from the start of the block. Always a multiple of MFTL_CACHE_LINE.

◆ MFTLGrowCapacity()

int MFTLGrowCapacity ( int current,
int needed )
inlinestatic

Geometric growth policy: at least needed, at least MFTL_INIT_CAPACITY, otherwise double until it fits.

A mesh that grows entity by entity therefore performs \(O(\log n)\) reallocations.

Parameters
currentPresent capacity. May be 0.
neededCapacity that must fit afterwards.
Returns
current if it already suffices, otherwise the smallest \(c_0 2^k \ge\) needed, with \(c_0\) = current, or MFTL_INIT_CAPACITY when current is 0. Saturates to exactly needed near INT_MAX instead of overflowing to a negative size.
