# ══════════════════════════════════════════════════════════════════════════════
#  MFTL -- documentation toolchain
#
#  Installed into .venv-docs by `python3 build_mkdocs.py`, which is the only
#  thing that needs it. Nothing here is required to build, test or use the
#  library itself.
#
#  Versions are pinned with `~=` (compatible release): patch and minor updates
#  are picked up, a major one is not -- in particular `mkdocs~=1.6` keeps MkDocs
#  below 2.0, which Material for MkDocs does not support. A documentation site that silently changes
#  its rendering between two machines is worse than one that refuses to install.
# ══════════════════════════════════════════════════════════════════════════════

# The site generator and the theme.
mkdocs~=1.6
mkdocs-material~=9.7

# The API reference: runs Doxygen, parses its XML, renders Markdown pages.
mkdoxy~=1.2

# Generates the guide, module-theory and analysis pages at build time from the
# repository's own Markdown -- see mkdocs/gen_pages.py.
mkdocs-gen-files~=0.6

# Quality-of-life: image lightbox, and HTML minification for the published site.
mkdocs-glightbox~=0.5
mkdocs-minify-plugin~=0.8

# export_manual.py only: one printable page of the whole manual, for the PDF.
